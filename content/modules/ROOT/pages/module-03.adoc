= Lab 3: Guest Agent Troubleshooting

== Overview & Objectives

- This lab focuses on diagnosing Virtual Machine readiness and IP visibility issues caused by QEMU Guest Agent failures in OpenShift Virtualization.
- Understand how OpenShift Virtualization relies on the Guest Agent for cluster-level routing visibility (IP addresses) and Load Balancer health checks.
- Troubleshoot Virtual Machine Readiness Probes (`guestAgentPing`) failing due to internal Guest OS service misconfigurations.

== Tasks

=== Task 1: Troubleshooting Readiness Probes and IP Visibility (The "Not Ready" VM)

==== Problem Scenario

- A Virtual Machine `vm4` is deployed in namespace `{{ bootstrap_tenant_username }}-troubleshoot-03`. The VM is in a `Running` state, but OpenShift refuses to route traffic to it because its `READY` status is `False` (0/1). 
- Additionally, the control plane is completely blind to the VM's internal IP addresses and Guest OS information.

==== Reference Documentation & Setup

- Consult the documentation on link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.14/html/virtualization/virtual-machine-management#virt-installing-qemu-guest-agent[Installing and configuring the QEMU guest agent].
- The VM has a `readinessProbe` explicitly configured to ping the Guest Agent, but a simulated security hardening script has masked the service inside the Guest OS upon boot.

==== Diagnostic Commands

Run the following commands to inspect the VirtualMachineInstance (VMI) status and observe the missing IP and Readiness state:

----
oc get vmi vm4 -n {{ bootstrap_tenant_username }}-troubleshoot-03
oc describe vmi vm4 -n {{ bootstrap_tenant_username }}-troubleshoot-03
----

*Diagnostic Checkpoints:*
- **CLI:** Look under the `READY` column; it will show `False`, and the `IP ADDRESS` column will be completely blank.
- **GUI:** Navigate to **Virtualization -> VirtualMachines** in the OpenShift Web Console. `vm4` will show a warning that the VM is not ready. Click on the VM and check the **Overview** tab: The `IP Addresses` and `Guest OS` cards will report as "Not available".
